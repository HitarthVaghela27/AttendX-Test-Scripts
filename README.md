# AttendX-Test-Scripts

## 1. Project Description
This repository contains sample demonstration test scripts
for the AttendX student attendance application.

The project demonstrates version control using Git and GitHub.

## 2. Files Included

### login_test.py
Demonstrates basic login input validation, including an
empty username test.

### attendance_test.py
Demonstrates student ID validation and attendance status
validation.

## 3. Requirements
- Python 3
- Git
- Visual Studio Code

## 4. How to Run

Open the terminal in the project folder and run:

```bash
python login_test.py
python attendance_test.py
```

If the `python` command is unavailable on Windows, try `py`.

## 5. Version Control
The project uses Git for local version history and GitHub
for remote storage and collaboration.

## 6. Limitation
These scripts are standalone demonstrations. They do not
connect to a live AttendX application, database, or API.
Real application automation requires the application's
URL or API, test environment, and approved test credentials.


Updated directly on GitHub to demonstrate collaboration and pull operations.
